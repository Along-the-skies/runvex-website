# Runvex Hosting website

A responsive static landing page for Runvex Hosting, a game-server hosting project in development.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. GitHub will show the published URL when deployment is ready.

## Before launch
- Confirm plans, pricing, supported games and launch dates before advertising them.
- This is a static site; it does not provision servers, accept payments or connect to Pterodactyl yet.
- The Discord invite is configured in `index.html`. Update it there if it changes.
